# domain/review — 복기·노트 교환 리뷰·신고

## 책임
틀린 문항의 원인을 가리고(복기), 서로의 노트에 의견을 남기고(노트 교환 리뷰), 문항 오류를 신고·이의제기한다.

## 규칙
- 복기 원인은 세 가지로 나눈다: **노트에 내용이 없음 / 노트 내용이 틀림 / 노트는 맞는데 제자가 적용하지 못함(AI 쪽 문제 가능)**.
- 서버의 자동 분류는 **제안일 뿐**이다. 최종 원인은 학생이 고르고, 다시 공부할 내용 메모를 남긴다. (AI 진단을 그대로 믿지 않는 연습)
- 복기 화면에는 제자의 답 / 근거가 된 노트 / 강의자료 근거 문장을 **나란히** 내려줄 수 있어야 한다.
- 상대의 노트는 **공개에 동의한 경우에만** 조회할 수 있고, 배틀을 함께 한 상대에게만 보인다.
- 리뷰에는 "좋았던 점"과 "보완할 점"을 근거와 함께 받는다.
- 문항 신고·이의제기가 접수되면 해당 문항을 `UNDER_REVIEW`로 바꿔 배틀에서 빼고, 검토 대기 목록에 올린다.
- 복기·리뷰 기록은 시험 사용에서 학습 효과를 확인하는 자료이므로 삭제하지 않고 쌓는다.
