# domain/ranking — Elo·전적·순위

## 책임
과목별 Elo, 친구 전적, 과목별 순위. (학과·단과대 대항전은 여유가 있을 때만 — P2)

## 규칙
- Elo(초기값 1000, K=32는 계획서의 초기 가정이다. 바꾸면 문서도 같이 고친다)는 **DB를 모르는 순수 계산 클래스**로 만들고 단위 테스트한다.
- 배틀 결과가 확정될 때 **한 트랜잭션에서 한 번만** 반영한다. 같은 배틀을 두 번 반영하지 않는다 (멱등성).
- 순위 집계에는 인증(학교 메일)을 마친 학생만 포함한다.
- 사용자·과목·학과 정보를 데이터에 포함해 두어 대항전·타 학교 확장이 가능하게 한다.
- 순위 조회는 페이지네이션을 쓴다. 전체 목록을 한 번에 내려주지 않는다.
