# domain/auth — 로그인·학교 메일 인증

## 책임
학교 메일로 재학생 인증 → 닉네임 정하기 → JWT 발급·검증. 인증을 거친 학생만 친구 대결·랭킹에 참여한다.

## 규칙
- 허용 메일 도메인은 설정값(`app.auth.allowed-email-domain`)으로 둔다. 코드에 박지 않는다.
- 인증 코드는 **해시로 저장**하고, 만료 시간과 시도 횟수 제한을 둔다. 코드 원문은 로그에 남기지 않는다.
- 인증이 끝나지 않은 사용자(`verified_at`이 비어 있음)는 배틀·랭킹 API를 쓸 수 없다. 이 검사는 한 곳(공통 로직)에서 한다.
- JWT 필터는 여기서 만들고 `global/config/SecurityConfig`의 필터 체인에 연결한다. 비밀키는 `.env`로만 받는다.
- 응답에는 이메일 전체를 돌려주지 않는다. 필요하면 마스킹한다.
- 닉네임은 중복·부적절 표현을 검사한다.
