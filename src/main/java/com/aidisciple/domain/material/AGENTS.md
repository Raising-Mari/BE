# domain/material — 강의자료 업로드·텍스트 추출

## 책임
PDF·텍스트 업로드 → 텍스트 추출 → **문장 단위로 쪼개 저장**(`material_sentence`). 문제 은행의 "근거 문장 확인"과 복붙 보정이 이 문장들을 기준으로 삼는다.

## 규칙
- 업로드 전 "본인이 사용 권한을 가진 자료만, 개인정보 제외" 안내에 **동의했는지를 서버에서도 검사**하고 기록한다.
- 확장자·MIME·크기를 검증한다 (크기 제한은 `spring.servlet.multipart`와 일치).
- 텍스트 추출은 시간이 걸릴 수 있으므로 **비동기로 처리하고 상태 조회 API**(`PENDING / DONE / FAILED`)를 둔다.
- 문장 분리·정규화(공백·문장부호 처리)는 순수 클래스로 만들고 한국어 예시로 테스트한다. 같은 정규화를 근거 문장 확인(`question`)과 복붙 보정(`grading`)이 공유한다.
- 추출 텍스트·파일 내용을 로그에 남기지 않는다.
- 녹음본(음성) 업로드는 후순위(P2)다.
