# ai/judge/ — 2차 검증(판정) 구현체

> **상태: 보류.** Jev API 접근 가능 여부를 확인하기 전까지 구현체를 만들지 않는다.

- 인터페이스(`JudgeClient`)는 "명제와 근거를 받아 판단 결과와 확률을 돌려준다"는 계약만 정한다.
- 문제 은행은 문항을 만든 모델(Gemini)과 **다른** 모델로 검증한다. 같은 모델을 쓰도록 바꾸지 않는다.
- 통과 기준(예: 일치율 0.8 이상)은 상수가 아니라 설정값(`app.ai.judge.threshold`)으로 둔다.
- Jev가 불가능하면 다른 모델로 구현체만 교체한다. 발표 시에는 교체 사실을 공개한다 (대회의 툴 공개 규정).
