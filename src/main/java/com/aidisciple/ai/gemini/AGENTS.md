# ai/gemini/ — Gemini 구현체

- `ai/`의 `LlmClient` 인터페이스를 구현한다. Gemini에만 해당하는 코드(엔드포인트, 요청·응답 형식)는 이 폴더 밖으로 새지 않게 한다.
- 모델 이름·타임아웃·최대 출력 길이는 `application.yml`의 `app.ai.gemini.*` 설정으로 뺀다. 코드에 하드코딩하지 않는다.
- 응답 스키마(JSON schema)를 지정해 형식이 깨질 가능성을 줄인다.
- 요청·응답 원문, API 키를 로그에 출력하지 않는다.
- 한도 초과·타임아웃은 전용 예외로 바꿔서 위로 올린다. (호출한 쪽이 사용자 안내를 정할 수 있게)
