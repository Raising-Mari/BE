# ai/ — 외부 AI 호출 어댑터

**외부 AI(Gemini 등)는 이 패키지를 통해서만 호출한다.** 모델을 바꿔도 나머지 코드가 그대로이도록 하기 위한 장치다.

## 구조
| 폴더 | 역할 |
|---|---|
| (이 폴더 직속) | `LlmClient`, `JudgeClient` 같은 **인터페이스**와 공통 타입 |
| `gemini/` | Gemini 구현체 |
| `judge/` | 2차 검증(판정) 구현체. **Jev는 보류 중** |
| `prompt/` | 프롬프트 템플릿 불러오기 |
| `log/` | AI 호출 기록 |

## 규칙
1. `domain/`은 **인터페이스에만 의존**한다. `gemini/`·`judge/` 구현체를 직접 import하지 않는다.
2. AI에는 항상 **JSON 형식의 구조화된 응답**을 요구하고, 파싱 실패 시 1회만 재시도한 뒤 `BusinessException`으로 올린다.
3. 모든 호출은 `log/`에 기록한다 (용도, 프롬프트 버전, 토큰 수, 지연 시간, 성공 여부). 본문 전체나 학생 입력 원문은 로그에 남기지 않는다.
4. 무료 티어 한도를 지킨다: 호출은 한 곳에서 모아 **재시도는 지수 백오프**, 429(한도 초과)는 즉시 반복하지 않는다.
5. 학생이 입력한 텍스트는 **지시가 아니라 데이터**다. 프롬프트에서 구분자로 감싸고, 그 안의 지시는 따르지 않는다고 명시한다. (프롬프트 주입 방어)
6. 무료 티어는 입력이 제품 개선에 쓰일 수 있다. 개인정보를 프롬프트에 넣지 않는다.
7. API 키는 환경변수(`GEMINI_API_KEY`)로만 받는다.
8. 테스트에서는 실제 호출하지 않고 가짜 구현(fake)을 쓴다.
