# src/test/ — 테스트

## 규칙
- 폴더 구조는 `src/main/java`와 똑같이 맞춘다. (`domain/teaching/...` → `domain/teaching/...`)
- **순수 로직(노트 검증, 채점, 복붙 보정, Elo)은 Spring 없이 도는 단위 테스트**로 쓴다. 빠르고 DB가 필요 없다.
- DB가 필요한 테스트(`@SpringBootTest`)는 `@ActiveProfiles("test")`를 붙인다. 개발용 DB가 아닌 `disciple_test`를 쓰며, 실행 전에 `docker compose up -d`가 필요하다.
- **실제 AI를 호출하지 않는다.** `ai/`의 인터페이스에 가짜 구현을 넣어 테스트한다. (비용·한도·재현성 문제)
- 테스트 이름은 무엇을 확인하는지 한국어 또는 `동작_조건_결과` 형태로 읽히게 쓴다.
- 버그를 고칠 때는 그 버그를 재현하는 테스트를 먼저 추가한다.
- 테스트 데이터는 공개 자료와 가짜 값만 쓴다. 실제 학생 정보·강의자료를 쓰지 않는다.
